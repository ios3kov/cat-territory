2. Win: reward, optional Personal Best, subdued stats and exactly one `Next level` CTA; no chapter/size transition plaque and no dynamic `Start N×N` label.

4. Keyboard: initial roving focus lands on an enabled cell and directional movement skips disabled starter cats; Enter/Space marks X and C toggles cat.
5. Endless: persistence, Hint, three-mistake restart, generated 8×8–10×10 levels remain functional.
6. Release gate: npm install, npm run typecheck, npm run build and npm run test:e2e must all pass before merging migration-1.1.7 into main.
